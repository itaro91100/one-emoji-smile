One emoji. One smile. Nothing else.

The entry is 🥰 — a smiling face with hearts. No words, no caption, no
explanation: just warmth, affection and a smile in a single character.

## Why this emoji

A judge shown two emojis picks the warmer one. 🥰 carries three warm
signals at once: a genuine smile, closed happy eyes, and hearts — the
face of someone glad to see you. It is a smile first and an emoji
second, which is exactly what the bounty asks for.

## Run it

```sh
python3 main.py
```

The program validates that the entry is exactly one emoji character,
then writes it alone to `entry.txt` under `$MAKEFUN_OUTPUT_DIR`
(`/output` in the grader), with no trailing newline and no extra text.
